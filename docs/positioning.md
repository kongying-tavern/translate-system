# 项目亮点

> 本篇按不同受众整理项目优势与话术，可直接用于官网文案、汇报或对外介绍。功能实现细节以 `.agents/` 各分册为准。

## 核心定位

- 不做大而全的本地化生态，专注「中小团队自托管的翻译管理」
- 部署五分钟起；译员在页面上顺手，程序员在命令行里也顺手

## 开发 / DevOps：程序员是一等公民

> 多数平台的隐含假设是「翻译人员在页面上点点点就够了」，程序员想批量拉取只能自己抓包猜接口。这个项目反过来——API 和脚本是一等交付物。

- 自带成套脚本，开箱即嵌：批量导入、翻译摘要报告、原子化目录锁定
- 脚本 PowerShell 与 Bash 双端齐发，Windows 团队不会被丢下
- 脚本参数为集成设计：项目标识 UUID / code 都认、语言支持代码别名、覆盖与自动创建语义显式声明——不用读源码猜行为
- 开放接口走白名单鉴权，两个请求头就能调；OpenAPI JSON 持续可用，直接导入 Apifox / Postman，CI 十分钟跑通
- 全接口统一响应结构，错误处理不用逐个试错
- 含 `/`、空格、中文的 Key 全链路安全；Key 改名不断链

## 译员 / 审校：打开就是一张大表

> 不用翻页搜索逐条点进去——筛出来、直接改、即时保存。

- 几十万条目一页流式浏览，虚拟滚动不卡顿
- 行内直接改译文，中文输入法组合期不丢字（专门处理过输入法时序问题）
- 按 `#行号`、`/正则/`、标签、「仅看未翻译」快速锁定要处理的条目
- 原文、上下文说明、备注都在手边，审校有依据
- 行高可调；遇到长句还能打开大编辑面板，不用挤在小格子里

## 项目经理：任务跑着不用盯

> 谁能做什么清清楚楚，批量任务全自动兜底。

- 三级项目角色（管理员 / 维护者 / 成员），菜单、按钮、数据三层控制，越权连接口都过不去
- 支持条目级锁定：锁定后仅维护者可编辑译文，审校期间防止误改
- 批量导入后台执行：实时进度、完成自动汇报新增 / 跳过明细、中途可叫停
- 同项目互斥锁，避免两人同时导入发生冲突
- 语言支持代码别名 + 显示名别名，导出键名和界面显示各按所需
- 导出模板一次配置，团队反复一键使用

## 技术决策者 / 运维：五分钟自建，没有账单

> 数据不出门，成本可预期。

- `docker compose up` 即起，数据库迁移随部署自动执行
- 数据完全在自己服务器，无订阅费、无按人头计费
- 登录态自动续期：多个页面同时过期也只会刷新一次，不会互相踢下线
- 开放接口使用 API Key 白名单鉴权，安全边界清晰
- 200MB 级大文件导入有现成的代理与内存调优方案
- 权限双重把关：无权限的功能在界面上自动隐藏；就算绕过页面直接调接口，后端也会拒绝
